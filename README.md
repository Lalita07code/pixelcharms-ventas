# 💜 PixelCharms Accesorios

Sitio web desarrollado para **PixelCharms Accesorios**, una marca de accesorios personalizados.

> ✨ Charms que suben tu nivel.

---

## 📌 Descripción del proyecto

Este proyecto consiste en el desarrollo de una página web responsive para PixelCharms Accesorios.

El sitio presenta las diferentes colecciones de la marca, opiniones de clientes y un formulario de contacto para que los usuarios puedan comunicarse.

---

## 🛍️ Colecciones

La página presenta cinco categorías principales:

- 🌈 Kids
- 💖 Cute
- 🎮 Gamer
- 💎 Piedras
- ✨ Elegancy

---

## 💻 Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Google Fonts

---

## 📱 Diseño Responsive

El sitio fue diseñado para adaptarse a diferentes tamaños de pantalla.

Se realizaron pruebas en:

- 📱 Dispositivos móviles
- 📱 Tablets
- 💻 Computadoras de escritorio

Para lograr la adaptación del contenido se utilizaron **Media Queries, Flexbox y CSS Grid**.
